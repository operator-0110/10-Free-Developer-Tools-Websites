## ⚡ Why This Collection?

You don't need to solve every development problem from scratch. These websites help you understand code, visualize concepts, test APIs, convert data, and work more efficiently.

## 🧭 Quick Reference

| Need | Tool |
|:---|:---|
| Find documentation | [DevDocs](https://devdocs.io/) |
| Understand shell commands | [ExplainShell](https://explainshell.com/) |
| Test regular expressions | [RegExr](https://regexr.com/) |
| Practice Git | [Learn Git Branching](https://learngitbranching.js.org/) |
| Learn algorithms | [VisuAlgo](https://visualgo.net/) |
| Visualize JSON | [JSON Crack](https://jsoncrack.com/) |
| Convert code and data | [Transform Tools](https://transform.tools/) |
| Draw flowcharts | [Excalidraw](https://excalidraw.com/) |
| Test APIs | [Hoppscotch](https://hoppscotch.io/) |
| Create code images | [Carbon](https://carbon.now.sh/) |

## 💡 Recommended Workflow

1. **Learn** — Use DevDocs and VisuAlgo to understand concepts.
2. **Build** — Use ExplainShell and Learn Git Branching while developing.
3. **Debug** — Test regex with RegExr and inspect API responses with Hoppscotch.
4. **Transform** — Explore JSON Crack and Transform Tools to handle structured data.
5. **Plan & Share** — Create diagrams with Excalidraw and code visuals with Carbon.
